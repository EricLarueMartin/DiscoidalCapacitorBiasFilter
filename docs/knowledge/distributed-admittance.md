# Distributed Frequency-Domain Admittance

## Purpose

The existing FEniCSx electrostatic solve extracts a Maxwell capacitance matrix,
and the SPICE/MNA solve combines that matrix with discrete stage resistances.
That is the correct first comparison model, but it does not solve current flow
and displacement current together in the physical filter volume.

The implemented first electrical field model calculates a complex nodal admittance matrix
directly from the filter geometry over frequency. It should answer three
separate questions:

1. How much source-voltage noise reaches the output after the detector and cable
   termination are applied?
2. What input and transfer admittances does the physical filter present?
3. How much thermal noise is generated by loss in the resistive core and,
   eventually, by dielectric loss?

Calling only `G_load + j omega C_total` a full admittance is not sufficient.
The required result is a multi-electrode field-derived matrix.

## Implemented First Model: Axisymmetric Electroquasistatics

For dimensions of a few centimetres and the current 1 Hz to 100 MHz circuit
range, the first field model should be electroquasistatic (EQS), not a
full-wave RF solve. The 62.5 MS/s ADC has a 31.25 MHz ordinary Nyquist edge.
It retains spatially distributed conduction and displacement current while
neglecting magnetic induction and radiation. Its strong form is

```text
div[(sigma + j omega epsilon) grad(V)] = 0
```

with `epsilon = epsilon0 epsilon_r`. The axisymmetric weak form retains the
same `2 pi r` volume factor used by the validated electrostatic model.

The Raspberry Pi PETSc installation may use real scalar arithmetic. The solver
must therefore not assume a complex PETSc build. With
`V = V_r + j V_i`, solve the coupled real system

```text
div(sigma grad(V_r) - omega epsilon grad(V_i)) = 0
div(sigma grad(V_i) + omega epsilon grad(V_r)) = 0
```

in a mixed real-valued function space. A complex build may be supported later,
but it must reproduce the coupled-real result.

The implementation is `software/bias_filter/admittance_fenicsx_solver.py`.
It meshes the complete full stack, applies a 1 V basis excitation to each bias
plate, extracts the complete complex nodal matrix with the reciprocal complex
energy bilinear form, and solves the terminated nodal equations with the input
fixed and the intermediate bias plates floating. The first and last bias
plates are therefore the driven input and measured output; this is not a
capacitance-only post-processing calculation.

Two transfer conditions are reported separately. The system-level result uses
the selected detector and cable termination. The intrinsic validation result
fixes the first bias plate at 1 V, leaves the last plate open-circuit, and
removes the input resistor, output resistor, cable, detector capacitance, and
load conductance. Only that intrinsic condition is compared with the bare
`G + j omega C_Maxwell` SPICE filter, because matching port conditions is
required for a meaningful field-versus-lumped validation.

Example on the FEniCSx host:

```bash
python3 software/bias_filter/admittance_fenicsx_solver.py \
  --parameters hardware/geometry/default-parameters.json \
  --frequencies 1 10 100 1000 10000 100000 1000000 10000000 100000000 \
  --mesh-mm 0.3 \
  --output simulations/electromagnetic/default-eqs-sweep.json
```

The current cable is a lumped capacitance in this EQS termination. That is a
useful comparison through its electrically short range, not a substitute for
a transmission-line or full-wave model at the high-frequency endpoint.

## Implemented Axisymmetric Full-Wave Reference

The first radiation-capable model is implemented in
`software/bias_filter/full_wave_meep_solver.py` using MEEP's cylindrical
full-wave Maxwell solver. It adds free space, PML absorption, magnetic
induction, independently calibrated input/stage/output core conductivities,
terminal-voltage probes, and outward Poynting-flux monitors. See
[`full-wave-maxwell.md`](full-wave-maxwell.md) for the saved results, corrected
monitor-coordinate issue, and validation limits.

Electrical smallness is not evidence that shielding is irrelevant. A
structure much shorter than a wavelength may still transfer energy through
fringing electric fields, inductive/common-mode coupling, and electrically
short leads or apertures. The displayed sweep begins at 50 Hz with EQS. A
single constant offset aligns MEEP to EQS at their shared 300 MHz point, while
the second shared 1 GHz point is retained as an independent handoff check. The
sweep continues through a solved point above the first verified local maximum so the mode is bracketed. The
grounded tube remains explicit in both field geometries.

It is an `m = 0` rotationally symmetric reference, not the final 3D model.
The following FEniCSx notes remain relevant to a later curl-conforming 3D
implementation.

## Future 3D Curl-Curl Extension

FEniCSx can support the intended full-wave extension. DOLFINx provides
curl-conforming Nedelec elements, Maxwell waveguide eigenmode examples, and
electromagnetic scattering examples with perfectly matched layers. The filter
model must solve the frequency-domain Maxwell curl-curl equation for vector
electric and magnetic fields; the present scalar EQS equation cannot be
relabelled as that result.

Unspecified interior and exterior regions should default to free space
(`epsilon_r = 1`, `mu_r = 1`, zero conductivity). Explicit epoxy, alumina,
core, conductor, and ferrite regions override those values. Open exterior
space requires a radiation boundary or PML so outward Poynting flux can be
separated from conductor, dielectric, and core loss. A closed ideal ground
tube has no radiation loss through its wall; energy can leave only through
modeled openings, ports, or nonideal conductors.

The first implementation should report input-to-output transfer, resonant
frequencies and Q, stored electric and magnetic energy, dissipated power by
material, and outward radiated power. An axisymmetric model is a useful first
reference for rotationally symmetric modes, but a 3D solve is required for
non-axisymmetric cavity/antenna modes, leads, connector openings, and the MELF
film geometry.

For an entered discrete resistance represented as a homogeneous surrogate,
assign each modeled resistive volume an effective conductivity

```text
sigma_effective = L / (R_entered A)
```

so that its low-frequency terminal resistance is the specified value. If the
user instead selects a bulk material, retain one common conductivity and let
each region's resistance follow its own `L/A`. The input and output matching
controls use this same distinction in the RC/SPICE model.

Relevant DOLFINx references:

- Maxwell waveguide eigenmode demo using curl-conforming elements:
  https://docs.fenicsproject.org/dolfinx/v0.9.0/python/demos/demo_half_loaded_waveguide.html
- Electromagnetic scattering with a perfectly matched layer:
  https://docs.fenicsproject.org/dolfinx/main/python/demos/demo_pml.html
- Axisymmetric electromagnetic scattering formulation:
  https://docs.fenicsproject.org/dolfinx/v0.7.0/python/demos/demo_axis.html

## Geometry and Materials

Reuse the validated conductor profiles, rounded edges, washer slabs, epoxy
regions, and ground tube from `fenicsx_solver.py`. Unlike the peak-field solve,
the resistive core is a solved material volume rather than an equipotential
bias boundary. Bias and ground plates remain equipotential electrode
boundaries.

Initial material treatment:

- Ferrite-like continuous core: derive conductivity from volume resistivity,
  with the ohm-cm to S/m conversion recorded explicitly.
- Alumina washer and epoxy: start with zero conductivity and zero loss tangent
  only as a comparison limit. Add measured DC resistivity and loss tangent as
  independent inputs before interpreting predicted noise.
- Copper plates and tube: ideal equipotential conductors for the EQS model.
- MELF option: an axisymmetric homogeneous cylinder calibrated to the entered
  stage resistance is only a surrogate. It cannot represent the helical film,
  end caps, solder joints, or routed resistor body. The eventual MELF result
  belongs in the 3D study.

Do not silently use electrostatic `epsilon_r` as a complete dielectric-loss
model. Every lossy material must report the source, temperature, frequency,
and uncertainty of its conductivity or loss tangent.

## Nodal Admittance Extraction

Treat every bias plate as an electrode port. For each frequency and each port
`j`, set that port to 1 V, all other bias ports to 0 V, and all ground
conductors to 0 V. Integrate complex normal current at every bias electrode:

```text
I_i = integral_Gamma_i (sigma + j omega epsilon) grad(V_j).n dA
Y_ij = I_i / 1 V
```

The implementation obtains the same terminal-current matrix through the
reciprocal complex-energy bilinear form. This avoids fragile facet-current
integration while preserving the complete complex port matrix. The resulting
full nodal matrix includes distributed resistive and capacitive
coupling in one solution. Internal bias plates are not prescribed in the final
transfer calculation: their zero-external-current conditions are enforced by
nodal KCL using this matrix.

Reduce the full matrix to input and output ports with a Schur complement only
for reporting a two-port. Retain the unreduced matrix in every result so its
internal-node behavior can be compared directly with the FEA-capacitance
SPICE ladder.

## Noise and Transfer Outputs

At each frequency report:

- Full complex `Y_ij` matrix and electrode order.
- Reduced two-port `Y11`, `Y12`, `Y21`, and `Y22`.
- Input impedance with the selected output termination.
- Complex `Vout / Vin` and attenuation in dB with the cable and detector load.
- Current density and electric-field magnitude by material.
- Joule-loss density `sigma |E|^2` and dielectric-loss density when loss
  tangent is enabled.
- Mesh, material properties, formulation, frequency, solve time, and memory.

Source-noise transfer and internally generated thermal noise are different
outputs. Source-noise attenuation uses `Vout / Vin`. For an equilibrium passive
field model, the fluctuation-dissipation starting point is the one-sided
current-noise covariance

```text
S_I(f) = 4 k_B T Re[Y(f)]
```

followed by the terminated network solution for output-voltage noise. This
must be checked against ordinary Johnson noise for a single resistor before it
is applied to the filter. Detector, cable, source, and amplifier noise remain
separate contributions.

## Required Comparison With SPICE

The existing FEA-capacitance SPICE model is the primary comparison, not a model
to remove. For the same electrode order and material assumptions, construct

```text
Y_lumped(f) = G_stage + j omega C_Maxwell
```

and compare it with `Y_field(f)` before adding cable or detector loading. Then
compare the loaded `Vout / Vin` curves. Report complex-matrix error as well as
attenuation error; matching one output curve can hide compensating matrix
errors.

The distributed solve is expected to approach the lumped result when the core
behaves as discrete uniform stage resistances, dielectric loss is zero, and
the physical scale remains quasistatic. Differences are useful: they identify
frequency-dependent current redistribution, continuous-core effects, and
coupling omitted by the lumped topology.

## Validation Gates

Do not use a distributed-admittance result for design conclusions until all of
these pass:

1. **DC resistance limit:** a uniform cylinder reproduces `R = rho L/A`.
2. **Electrostatic limit:** with `sigma = 0`, `Im(Y)/omega` reproduces the
   validated Maxwell capacitance matrix on the same mesh.
3. **Single-RC limit:** one conductive path and one shunt dielectric reproduce
   the analytical divider and SPICE/MNA result.
4. **Reciprocity:** `Y_ij` and `Y_ji` agree within the stated numerical
   tolerance.
5. **Passivity:** the real part of the admittance matrix has no materially
   negative dissipative mode after accounting for numerical tolerance.
6. **Mesh convergence:** matrix entries, transfer, and integrated loss converge;
   do not use raw point current density as the primary stop criterion.
7. **Frequency limits:** the lowest and highest decade are repeated with tighter
   meshes and frequency spacing.
8. **Noise limit:** a single resistor gives `4 k_B T R` open-circuit voltage
   noise and `4 k_B T/R` short-circuit current noise under consistent one-sided
   conventions.

## Implementation Order

1. Add material conductivity and optional loss-tangent parameters without
   changing the current electrostatic solve.
2. Add tagged electrode facets and verify terminal-flux integration against
   electrostatic charge/capacitance.
3. Implement the coupled-real axisymmetric EQS basis solve for a one-stage
   continuous-core geometry.
4. Pass the validation gates above.
5. Extend to the full bias-node matrix and compare with SPICE from 1 Hz to
   100 MHz.
6. Add terminated source transfer, then internal thermal-noise calculations.
7. Only after the axisymmetric reference is stable, use the same formulation in
   the 3D symmetry study.

This ordering follows the project decision to make FEniCSx the reference before
improving the JavaScript browser solver.
