# Presentations

This section hosts web-based presentations and design views that can be viewed in a browser, version-controlled, and eventually published with GitHub Pages or another static site host.

Start with `web/index.html`. The page opens on the slide deck; the interactive geometry and electric-field Designer remains available as a tab. The slides render their geometry and browser-side simulation previews from the same startup settings as the Designer. The repository publishes this directory at `https://ericlaruemartin.github.io/DiscoidalCapacitorBiasFilter/` through GitHub Pages.

The deck uses a linked table of contents. Its five-slide **Main presentation** contains only the title, the complete-filter SPICE result, the present MELF shortfall, the ferrite design conclusion, and the recommended way forward. The SPICE result overlays the loaded transmission-line case, the ordinary unloaded-output case, and the intrinsic direct-drive/open-output transfer used for comparison with the field solve. Model definitions, capacitance extraction, peak-field FEA, the matched open-circuit EQS/SPICE comparison, and resonance comparisons are grouped under **Models & FEA results**; detailed checks remain under **Validation & limiting cases**, and supporting trade studies remain under **Engineering decisions**. Every entry is a URL fragment, so a specific slide can be bookmarked or linked directly. The contents rail stays at the left on larger screens and is collapsible above the slide on narrow screens.

The deck can be opened directly from `web/index.html`; its committed default-geometry FEniCSx field, exact capacitance extraction, and ngspice sweep are loaded through a relative classic-script link that works under both `file://` and GitHub Pages. The optional installation-local `default.json` still requires HTTP. To test that file too, serve `web/` over HTTP—for example, run `python -m http.server 8000` there and open `http://localhost:8000/`. New backend FEA, SPICE, thermal, and artifact features still require the project server.

Each deployment may put an untracked `default.json` beside `index.html`. At startup the page loads that file when present, using the same format accepted by **Import JSON**; otherwise it uses the built-in defaults. Choose settings in the Designer and use **Download default.json**, then copy the downloaded file beside `index.html` on that installation and reload. `default.json` is deliberately ignored by Git so one deployment's default does not change another's. **Reset** returns to the loaded installation default.

The engineering backup section includes the checked-in 1050-O aluminum and
annealed-copper thermal comparison. Aluminum modestly reduces bulk-epoxy
tension but does not help the fitted-alumina layout. The annealed-copper J2
case is explicitly a perfect-plastic sensitivity, with matched-mesh elastic
references, rather than a qualified material prediction.

The electromagnetic slide is deliberately scoped as a first frequency-domain, quasi-static network extension. It combines the current node-resolved FEniCSx Maxwell capacitance matrix with a coaxial partial-inductance estimate derived from the axial stage length, core radius, and grounded-tube radius. It compares a low-loss reference, which exposes the coupled LC resonances, with the selected physical interstage resistance, which strongly damps them. A separate single-mode RLC check uses the mean solved node-to-ground capacitance and chooses an effective inductance so its zero-resistance natural frequency matches the first coupled-model peak. Applying the same physical resistance then checks that both descriptions predict the same damping regime and resonance scale; it does not require their complete multi-stage transfer amplitudes to be identical. This is an internal consistency check, not independent electromagnetic validation. The model is not presented as a 3D full-wave solution: the next verification step is a 3D curl-curl model with conductor and dielectric losses and comparison with a measured impedance or S-parameter sweep. The external cable is excluded from this high-frequency chart because its lumped-capacitance representation is no longer valid there.
